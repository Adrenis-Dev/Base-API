## ⚙️ Instalação

## Clone o repositório

```bash
git clone https://github.com/DeltaTempest-dev/Base-API.git
```

## Entre na pasta

```bash
cd Base-API
```

## Instale as dependências

```bash
npm install
```

## Inicie o projeto

```bash
npm start
```
